The moat — only on Solana

A CPI primitive
EVM structurally can't match.

caller program ──CPI──▶ mppsol_cpi │ ├─ pay_with_receipt ───▶ payment + on-chain Receipt PDA ├─ SettleViaSession ───▶ session debit + receipt └─ verify_paid_result_with_receipt ├─ Ed25519-verifies server's signed result └─ asserts Receipt PDA matches (atomic binding) Anyone composes paid off-chain resources (oracles, KYC, signal feeds) into Solana programs, atomically. Receipt PDAs persist across CPIs and tx boundaries. Atomic on-chain payment-binding shipped v0.1.1. Why EVM can't: no atomic multi-instruction tx model + no Ed25519 precompile pattern for cheap on-chain verification.
